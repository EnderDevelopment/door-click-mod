# Door Click Mod

A Minecraft mod that rewards players with random items for clicking doors.

## Features

- Random item rewards for clicking doors multiple times
- Supports both cookies and TNT as possible rewards

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.3 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/door-click-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

1. Play the game normally.
2. Click on any door three times.
3. Receive a random item (cookie or TNT) in your inventory.

## Configuration

The mod does not have a configuration file. The behavior is fixed: clicking a door three times gives you a random item.
